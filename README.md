# Takedown Resource Kit (TRK)

A comprehensive, free, and anonymous resource kit designed to help victims of non-consensual intimate imagery (NCII) and digital abuse take back control.

## Key Features

- **Step-by-Step Takedown Guides**: Direct links and pre-written templates for major social media platforms (Meta, X, TikTok, Reddit, etc.) and search engines.
- **India-Specific Resources**: Detailed legal rights under the IT Act and Bharatiya Nyaya Sanhita (BNS), and contact info for state-wise cybercrime units.
- **Evidence Preservation**: Guidance on how to safely document abuse before requesting takedowns.
- **Digital Security Guide**: Instructions for securing accounts via 2FA, password management, and session monitoring.
- **Progress Tracker**: A private, local-storage based checklist to help victims manage their recovery process without leaving a data trail.
- **Quick Exit**: A "panic button" (and Escape key shortcut) to immediately redirect the browser to a neutral page.

## Privacy First

- **No Cookies**: We do not use any tracking cookies.
- **No Data Collection**: The Progress Tracker saves data only to your browser's local storage.
- **Anonymous**: No login or registration required.

## How to Use

Simply navigate the static pages to find the resources you need. 

## Disclaimer

This website provides general information and tools to help victims. Content provided does not constitute formal legal advice. If you are in immediate physical danger or need specific legal counsel, please contact local law enforcement or a qualified attorney.
